Privacy Policy — gmail-import

Last updated: 7 October 2026

What the app is

gmail-import is a personal command-line tool that runs only on its owner's computer. It is used by the owner to access their own Google accounts. It is not offered to the public.

What Google data it accesses

With the user's consent, the app requests the read-only Gmail scope (https://www.googleapis.com/auth/gmail.readonly). It reads message metadata, message bodies and attachments that match searches the user runs.

How the data is used and stored

  • Messages and attachments are downloaded to and stored on the user's own computer only.
  • OAuth tokens are stored locally on the same computer and are never shared.
  • The app never sends, modifies or deletes email.
  • Text of selected documents may be sent to the Anthropic Claude API, at the user's own request, to help summarise and organise the user's own documents. It is not used for any other purpose.

Sharing

Google user data is not sold, not used for advertising and not shared with any third party, except the processing described above that the user requests.

Limited Use

The use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token files and downloaded files removes all data held by the app.
